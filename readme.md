# Dream Gate Multi Technologies Projects Ltd. — Website

A responsive, premium single-page company website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. For best local development, use VS Code Live Server.

## Deploy
Upload `index.html`, `styles.css`, and `script.js` to your hosting provider's public web root, or deploy this folder to Netlify/Vercel as a static site.

## Included
- Responsive navigation and mobile menu
- Hero, company overview, service cards, client references, CTA, and contact sections
- Scroll-to-section navigation and subtle reveal effects
- Contact form that opens the visitor's email app with a pre-filled enquiry
- WhatsApp quick-contact link
- Reduced-motion support

## Before publishing
- Confirm all company details, service descriptions, and client references with Dream Gate.
- Replace stock photography with approved company/project photography for the strongest result.
- The enquiry form uses `mailto:` and does not save submissions. For a production lead pipeline, connect a backend or form service.
- Add official social profile links and analytics if needed.
